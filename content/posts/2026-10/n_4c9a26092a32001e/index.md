## 二、按键连接总表

### 直连键（K1~K10，无二极管）

| 按键 | 连接IO | 连接IO |
| :--- | :--- | :--- |
| K1 | IO1 | IO2 |
| K2 | IO1 | IO3 |
| K3 | IO1 | IO4 |
| K4 | IO1 | IO5 |
| K5 | IO2 | IO3 |
| K6 | IO2 | IO4 |
| K7 | IO2 | IO5 |
| K8 | IO3 | IO4 |
| K9 | IO3 | IO5 |
| K10 | IO4 | IO5 |

每个按键就是普通轻触开关，两端分别接对应的两个IO口，中间无任何元件。

### 二极管键（K11~K14，共4个二极管）

| 按键 | 阳极侧接IO | 阴极侧接IO | 二极管方向 |
| :--- | :--- | :--- | :--- |
| K11 | IO3 | IO1 | 阳极→IO3，阴极→IO1 |
| K12 | IO4 | IO1 | 阳极→IO4，阴极→IO1 |
| K13 | IO5 | IO1 | 阳极→IO5，阴极→IO1 |
| K14 | IO4 | IO2 | 阳极→IO4，阴极→IO2 |

具体接法（以K11为例）：

```text
IO3 ──── 按键K11 ──── 二极管阳极 ──▶|── 二极管阴极 ──── IO1
```

```
IO1 ──┬── K1  ── IO2
      ├── K2  ── IO3
      ├── K3  ── IO4
      ├── K4  ── IO5
      ├── K11 ── 二极管(阳IO3,阴IO1) ── IO3
      ├── K12 ── 二极管(阳IO4,阴IO1) ── IO4
      └── K13 ── 二极管(阳IO5,阴IO1) ── IO5

IO2 ──┬── K5  ── IO3
      ├── K6  ── IO4
      ├── K7  ── IO5
      └── K14 ── 二极管(阳IO4,阴IO2) ── IO4

IO3 ──┬── K8  ── IO4
      └── K9  ── IO5

IO4 ──┬── K10 ── IO5
```
